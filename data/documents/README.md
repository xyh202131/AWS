# DraftOps Document Library

This folder stores reference documents that support competition reasoning but are not raw data tables, generated boards, or final submission artifacts.

## Categories

- `milestone-questions/`: milestone and exam-question design references.

## Rules

- Preserve copied documents as source references; do not rewrite their contents in place.
- Put classification metadata in `document_index.json`.
- Use SHA256 hashes when importing external local files so later agents can verify integrity.
