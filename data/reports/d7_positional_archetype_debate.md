## 1. Executive Recommendation

D7 should not add a blanket position bonus for "guard", "wing", or "big". The current 30-player pool already has plenty of guards and generic frontcourt bodies. The scarce value is concentrated in specific modern NBA archetypes:

1. Big wing / wing creator with size and two-way indicators.
2. Primary guard only when paired with shooting, size, or real defensive viability.
3. Rim protector only when paired with feel, mobility, passing, shooting, or elite defensive size.
4. 3-and-D / switchable defense with enough shooting to stay on the floor.
5. Connector forward/frontcourt profiles that add feel, passing, defense, and low-usage scalability.

Recommended source-compatible base weights:

```json
{
  "consensus": 34,
  "need": 26,
  "player": 25,
  "upside": 8,
  "intel": 7
}
```

Why this mix:

- `player` rises because archetype quality is mostly embedded in profile skills: shooting, creation, defense, feel, and size.
- `need` rises slightly, but not enough to let low-confidence team tags force reaches.
- `consensus` stays in the mid-30s because the top of the board and source-depth risks still need protection.
- `upside` stays below the A4 upside-heavy recommendation because role scarcity should reward translatable skill combinations, not raw tools alone.
- `intel` is trimmed because source heat should not double-count consensus or over-protect thin supplemental ranks 26-30.

If a future code change adds an explicit sixth signal, D7 would prefer this conceptual shape:

```json
{
  "consensus": 34,
  "need": 22,
  "player": 24,
  "upside": 8,
  "intel": 6,
  "roleScarcity": 6
}
```

Do not fake `roleScarcity` by pushing `need` above the low 30s. That would over-trust team need rows that are marked `needs_review`.

## 2. Current Model Finding

`src/lib/prediction.ts` already recognizes role tags through `tagAliases` and `tagFamilies`, but those tags mainly enter the score through team-need matching. The current model does not have an independent positional scarcity or archetype scarcity signal.

Important current behavior:

| Model area | Current behavior | D7 concern |
| --- | --- | --- |
| `getNeedScore` | Rewards direct role-tag and fuzzy team-need matches. | Good for fit, but a scarce archetype only matters when a team tag asks for it. |
| `getPositionBonus` | Gives a flat +10 when team need maps to guard, wing/forward, or PF/C. | Too broad. A small scoring guard and a big two-way guard can receive the same position treatment. |
| `getPlayerScore` | Averages shooting, creation, defense, athleticism, feel, and size, then adjusts by phase. | Directionally sound, but it can understate rare combinations such as big-wing shooting plus defense. |
| `getUpsideScore` | Uses upside, age, risk tolerance, and draft zone. | Helps young tools, but does not know whether the tools form a scarce NBA role. |
| Risk penalty | Captures medical, shooting, strength, decision, and young-contender fit risks. | Does not explicitly punish one-dimensional non-spacing bigs, undersized guards, or generated/source-risk archetypes. |

Bottom line: D7 should be implemented as a small role-quality layer, not as a replacement for consensus or team fit.

## 5. How Scarcity Should Affect Picks

### Picks 1-5

Scarcity should only order players inside the same elite tier. It should not justify a major reach.

Practical stance:

- AJ Dybantsa and Caleb Wilson gain value because big wing creation/two-way size is the hardest star archetype to find.
- Cameron Boozer gains value because he is not a traditional big; he is a frontcourt engine/connector.
- Darryn Peterson and Keaton Wagler gain value because they are not generic guards; they combine creation or shooting with enough size.
- Do not move a lower-consensus specialist into the top five only because a team has a positional need.

### Picks 6-14

Scarcity can move players 1-2 consensus slots when team fit and player grade agree.

Examples:

- Aday Mara can be protected for teams needing real rim protection because clean anchor supply is thin.
- Nate Ament and Karim Lopez should not slide too far because size plus shooting/defense remains scarce.
- Brayden Burries is more valuable than a generic guard because he has a two-way guard frame.
- Morez Johnson Jr. should not be lifted aggressively by frontcourt demand unless the model accepts his low shooting/creation/feel tradeoff.

### Picks 15-30

Scarcity can matter more, but only for clean archetype bets:

- Late-first teams should be allowed to lift Dailyn Swain, Allen Graves, Isaiah Evans, Sergio De Larrea, or Chris Cenac Jr. when the role is scarce and the team context fits.
- Jayden Quaintance is a conditional scarcity bet: age, size, defense, and upside are real, but medical and feel/shooting risk must gate the pick.
- Tarris Reed Jr. should not rise because of "center depth" alone; his profile has source-quality and low-skill-risk problems.
- Multi-pick teams should not double-count one scarcity tag. If a team already selected a frontcourt defender, the next pick should not receive the same scarcity premium unless it adds a different skill package.

- A wing/forward who combines defense, size, and shooting/feel should receive the cleanest scarcity lift.

## 9. Final D7 Stance

D7's board philosophy:

1. Protect the elite scarce archetypes at the top: big wing creation, frontcourt connector, and big guard shooting.
2. In the lottery, let scarcity break same-tier ties but do not let it create 3+ slot reaches.
3. In the late first, use scarcity more aggressively for clean multi-skill wings, connectors, and modern bigs.
4. Treat pure small guards and traditional non-spacing centers as replaceable unless consensus, player grade, or special upside says otherwise.
5. Keep need confidence gates from D5. Scarcity plus weak need evidence is still weak evidence.

Bottom line: use `34/26/25/8/7` as the current-source D7 parameter set. If the product later supports a sixth signal, move four points out of `need/intel` into a capped `roleScarcity` score rather than inflating the existing team-need slider.
